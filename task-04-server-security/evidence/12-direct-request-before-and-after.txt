PART 4: ARCHITECTURAL LESSON & CONCLUSION
================================================================================
In Task 3, we proved that client-side forms provide zero security. An attacker simply writes 10 lines of Node.js to invoke the HTTP endpoint directly, bypassing all UI error banners, red borders, and disabled buttons.

In Task 4, by enforcing strict Zod boundary validation schemas at the Next.js API route layer, the server acts as the authoritative source of truth. Every rule previously enforced in the browser (Nigerian phone numbering structure, mandatory NDPA privacy consent, minimum name parts, and password complexity) is verified before the request touches the database, argon2 hasher, or downstream workers.

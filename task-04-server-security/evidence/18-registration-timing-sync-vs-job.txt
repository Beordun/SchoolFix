--- ARCHITECTURAL CONCLUSION ---
Sending emails or SMS notifications inside the synchronous HTTP request thread is an architectural anti-pattern:
1. It ties client response time to third-party mail server availability and latency.
2. If the mail server experiences network congestion or rate limits, the registration transaction times out and fails, causing users to retry and create duplicate accounts.
3. Offloading delivery to an asynchronous queue ensures the registration transaction commits cleanly in PostgreSQL, and delivery retries happen independently without degrading frontend responsiveness.
